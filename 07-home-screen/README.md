# 07 - Home Screen

## Deskripsi

Pada materi ini dikembangkan **Home Screen** sebagai halaman utama aplikasi
Wisata Candi dengan menggunakan `GridView.builder` untuk menampilkan daftar
candi dalam bentuk grid.

Setiap item pada grid diimplementasikan sebagai custom widget `ItemCard`
agar kode lebih terstruktur dan mudah digunakan kembali.

## Tujuan Pembelajaran

- Menggunakan `GridView.builder`.
- Mengimplementasikan `SliverGridDelegateWithFixedCrossAxisCount`.
- Membuat custom widget menggunakan `StatelessWidget`.
- Menampilkan data dalam bentuk grid.
- Menyusun tampilan menggunakan `Card`, `Column`, dan `Expanded`.
- Menampilkan gambar menggunakan `Image.asset`.

## Materi

- GridView.builder
- SliverGridDelegateWithFixedCrossAxisCount
- Card
- RoundedRectangleBorder
- Expanded
- ClipRRect
- Image.asset
- Column
- Padding
- StatelessWidget
- Custom Widget (ItemCard)

`GridView.builder` dan custom widget `ItemCard` sebagai komponen utama
penyusun antarmuka.
