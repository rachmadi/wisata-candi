# 04 - Sign In Screen

## Deskripsi

Pada materi ini dikembangkan **Sign In Screen** sebagai contoh penerapan form,
TextFormField, dan pengelolaan state sederhana pada Flutter.

## Tujuan Pembelajaran

- Membuat Sign In Screen.
- Menggunakan Form dan TextFormField.
- Menggunakan TextEditingController.
- Menggunakan InputDecoration.
- Mengatur tampilan dengan Padding dan SingleChildScrollView.
- Mengubah StatelessWidget menjadi StatefulWidget.
- Mengimplementasikan show/hide password menggunakan `obscureText`.

## Materi

- Form
- TextFormField
- TextEditingController
- InputDecoration
- OutlineInputBorder
- ElevatedButton
- TextButton
- SingleChildScrollView
- StatefulWidget
- obscureText
