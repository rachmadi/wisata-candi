# 02 - Detail Screen

## Deskripsi
Implementasi tampilan Detail Screen aplikasi Wisata Candi.

## Tujuan Pembelajaran
- Menyusun layout menggunakan Column dan Row.
- Menggunakan Stack.
- Menampilkan gambar.
- Menggunakan CachedNetworkImage.
- Membuat galeri horizontal.

## Hasil Akhir
Detail Screen telah selesai dibuat namun belum memiliki fitur interaktif.
